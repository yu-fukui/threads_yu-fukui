# 代表のメモを yu の投稿にする手順

2026-11-07 代表「両方」（統括の案「情報×感情」の B）。
代表が週に数回、短いメモ（今日あったこと・思ったこと）を送り、AI が投稿の形に整えて yu から出す。
**AI は想いや体験を作らない。** 代表の言葉を整えるだけ。

## 流れ

1. 代表がメモをメインセッションに送る（そのままの文で）
2. メインセッションがおでかけ開発に回す（代表の原文をそのまま）
3. おでかけ開発が整えて、posts/queue.jsonl に1本足し、main に push する
   - 時刻：その日の **19:00**（受け取りが 18:00 を過ぎたら翌日の 19:00）。19:00 は自動の作成が使わない時刻
   - 19:00 がすでに埋まっていたら、その日の 12:00 → 翌日の 19:00 の順で空きを探す
   - id は `p-YYYYMMDD19-memo`、note は「代表のメモ（MM/DD 受け取り。整えただけ）」
   - 投稿は threads-post.yml（10分ごと）が時刻になったら出す
4. 足したら、整えた本文と出る時刻をメインセッションと統括に知らせる。代表が「消して」と言えば出る前に外す（出たあとは代表の「消して」で消す）

代表の確認は**要らない**（代表の言葉を整えるだけで、事実も気持ちも足さないため）。代表が確認したいときは「確認してから」とメモに書けば、整えた文を先に返し、「出して」で入れる。

## 整え方の決まり

- 代表の言葉・言い回しをなるべく残す。並べかえ・改行・誤字・「です・ます」をそろえる程度
- **足さない**：体験・気持ち・数字・場所・人の言葉を作らない。メモに無い結論や教訓も足さない
- **外す**（外したらメインに知らせる）：クライアントの実名・個人の名前・金額・社内の事情・まだ公開していないこと
- 500字以内。長いときは2本に分けず、言葉を削らずに返信（thread）に続ける
- 宣伝・リンク・PR・アフィリエイトは入れない。ハッシュタグは付けない
- 読む人への問いかけは、メモに問いがあるときだけ
- AI の呼び出しは使わない（おでかけ開発が整える。費用は増えない）
