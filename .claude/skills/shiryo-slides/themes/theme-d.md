# テーマ D — クラフト

教材・勉強会・社内共有向け。クラフト紙のような生成り地に深緑。
**5 テーマで唯一、黄（`--spark`）を差せる。**

- 想定: 講座・研修の投影資料、勉強会の配布資料、社内共有のまとめ・振り返り
- 性格: クラフト紙のような地に深緑。**5 テーマで唯一、黄を差せる**

> **このテーマが持つのは配色・書体・スケールだけ。** 黒枠やオフセット影は持ち込まない。
> 💡電球バッジ・ミニ集中線。1 枚絵の図解で効く装飾で、複数枚のデッキでは過剰になる。
> **`--spark`（黄）だけは残した**（§1-4）。教材で「ここが答え」を 1 点だけ示す用途に効くため。
> **デッキ全体で 1〜2 箇所**に絞る。

---

## 1. カラートークン

```css
:root{
  /* ライト面 */
  --bg:              #F6F3EA;   /* 地（クラフト紙のような生成り） */
  --surface:         #FFFFFF;   /* カード・パネル面 */
  --ink:             #232323;   /* 主テキスト */
  --sub:             #5C594F;   /* 副テキスト */
  --dim:             #8a8474;   /* ラベル・ページ番号（本文には使わない。§1-3） */
  --line:            #ded7c6;   /* 罫線 */

  /* アクセント */
  --accent:          #1E8A3C;   /* 面・図形のみ。文字には使わない（§1-3） */
  --accent-deep:     #14682C;   /* 文字用・白文字を載せる塗り用 */
  --accent-tint:     #E3EFE4;   /* 淡い面 */

  /* 第 2 アクセント（このテーマだけが持つ。面専用。§1-4） */
  --spark:           #FFD84D;   /* 「到達点・答え」のマーカー／小さな塗り */

  /* ダーク面（面ルールが許可する範囲でのみ使用。§2） */
  --ink-surface:     #232323;   /* ダークブロックの地 */
  --on-dark:         #F6F3EA;   /* ダーク面の主テキスト */
  --accent-on-dark:  #52c46e;   /* ダーク面のアクセント */
  --line-on-dark:    #3d3d3d;   /* ダーク面の罫線 */

  /* 形状・書体 */
  --radius:          4px;
  --ff:    "Zen Kaku Gothic New","Hiragino Sans","Yu Gothic","Meiryo",sans-serif;
  --ff-en: "Manrope","Helvetica Neue",Arial,sans-serif;
}
```

### 1-1. Web フォント

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Zen+Kaku+Gothic+New:wght@500;700;900&family=Manrope:wght@700;800&display=swap" rel="stylesheet">
```

表紙の h1 に 900、中面見出しに 700 を使う（§3）。900 と 700 の落差がこのテーマの見え方を決める。

**`--ff` / `--ff-en` のローカル代替は必ず残すこと。** 社内プロキシで Google Fonts が塞がれた環境・オフライン環境では CDN が届かない。
特に **Zen Kaku Gothic New が落ちるとヒラギノ／游ゴシックに落ち、900 が出ないため表紙が痩せる**（700 相当で頭打ちになる）。
`capture.js` は撮影時にフォントが届いたかを検査し、落ちていれば警告する。社内配布用途が多いテーマなので、この警告は必ず確認する。

### 1-2. コントラスト実測値

すべて WCAG 2.1 の相対輝度比で実測済み。

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--ink` / `--bg` | 14.17 | AA 本文可 |
| `--sub` / `--bg` | 6.32 | AA 本文可 |
| `--dim` / `--bg` | 3.36 | **本文不可**・ラベルのみ |
| **`--accent` / `--bg`** | **3.98** | **文字不可**・大文字基準のみ通過（§1-3） |
| `--accent-deep` / `--bg` | 6.21 | AA 本文可 |
| `#fff` / `--accent-deep`（塗りの上） | 6.89 | AA 本文可 |
| **`#fff` / `--accent`（塗りの上）** | **4.42** | **本文不可**（§1-3） |
| `--ink` / `--accent-tint` | 13.27 | AA 本文可 |
| `--ink` / `--spark`（黄の塗りの上） | 11.36 | AA 本文可 |
| `--on-dark` / `--ink-surface` | 14.17 | AA 本文可 |
| `--accent-on-dark` / `--ink-surface` | 7.09 | AA 本文可 |

### 1-3. 文字色の規約

1. **`--accent`（`#1E8A3C`）を文字色に使わない**（3.98:1）。大文字基準 3:1 は通るが本文には届かず、見出し強調に使うと隣の `--ink` と明度が近くて「濃い緑の黒」に見える。強調語・ラベルは **`--accent-deep`（`#14682C`、6.21:1）**
2. **文字を載せる塗りは `--accent-deep` ＋ 白文字**（6.89:1）。`--accent` 塗りに白文字は **4.42:1** で不可。`--accent` の塗りは**文字を載せない装飾専用**（区切り帯・ドット・下線・図形）にする
   - 数値と印象が食い違うときは、**文字を明るくするのではなく面を濃くする**
3. **`--dim` は本文に使わない**。ページ番号・KI ラベル・「出典」などの短い補助ラベル専用。読ませる文章は `--sub` 以上
4. ダーク面の上では `--accent-on-dark`（7.09:1）が使える。ここは制約が緩い

### 1-4. `--spark`（黄 `#FFD84D`）の規約 — このテーマ専用の第 2 アクセント

1. **面のみ。文字色にするのは禁止。** 生成り地の上の黄文字は読めない
2. 用途は **「到達点」「答え」「ここが要点」を示すマーカー／小さな塗り**だけ。1 スライドに 1 箇所、**デッキ全体で 1〜2 箇所まで**
3. **黄の上に載せる文字は必ず `--ink`**（11.36:1）。白文字は使わない
4. **散らすと安っぽくなる。** 見出し下線・強調語のマーカー・小バッジのどれか 1 種に決め、同じデッキ内で使い分けない
5. `--accent`（緑）の塗りとは役割が違う。緑＝構造の色、黄＝結論の色。**同じ塊の中で両方を使わない**

## 2. 面ルール

| レベル | 規定 |
|---|---|
| **全面ダーク** | **0 枚**。作らない。生成り地が思想であり、表紙も例外にしない |
| **ダークブロック** | 1 スライドに **1 個まで**。デッキ全体で **1〜3 枚**。3 枚連続不可。用途は「ここが結論／主役」を示す 1 要素（テーブルの強調行、対比の主役側、要点バー） |
| **アクセント面** | `--accent` 塗りは 1 スライドに 1 箇所まで。並列カードの一部だけを塗るのは禁止 |
| **`--spark` 面** | 1 スライドに 1 箇所、デッキ全体で **1〜2 箇所**（§1-4） |

### 2-1. 強調面

専用トークンは持たない。**地を `--surface`（白）、その上のカードを `--bg`（生成り）に反転する**。2〜3 枚に 1 回程度。

## 3. スケール（テーマが上書きする 6 値）

| 用途 | 値 |
|---|---|
| h1 サイズ（表紙） | `60px` |
| h1 ウェイト | `900` |
| h2 サイズ（中面見出し） | `32px`（2 行化時のみ `30px`） |
| h2 ウェイト | `700` |
| 本文サイズ | `16px`（最小 `14px`） |
| KI ラベルサイズ | `11px` |

**900 は表紙の h1 だけ。** 中面見出しを 900 にすると教材の落ち着きが消え、C（モダン）に寄る。

**この 6 値以外のサイズ（カード見出し・番号・SVG ラベルの最小値・余白・グリッド）はレイアウト層（`core/rules.md`）が持つ。** テーマ側で上書きしないこと。

## 4. このテーマの空気感

- **箱で囲わず、罫線と余白で仕切る。** 黒枠は使わない。カードは「まとまりを明示する必要がある」ときだけ
- **角丸 4px。** 紙の質感に対して角丸を大きくすると、教材ではなく販促物に見える
- 生成り地（`#F6F3EA`）と白面（`#FFFFFF`）の差は小さい。**面を分けたいときは罫線を併用する**
- 緑は「1 スライドに 1 箇所」、黄は「デッキに 1〜2 箇所」。**緑で構造を示し、黄で到達点だけを示す**。両方を散らすと配色の意味が消える
- 情報量は B（中庸）と同程度まで詰めてよい。**投影しながら手元でも読む**教材が主用途で、C ほど絞り込まなくてよい。ただし 1 枚 1 メッセージは守る
