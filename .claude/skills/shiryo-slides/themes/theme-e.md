# テーマ E — 生成り

登壇・SNS・スタートアップ向け。生成り地に朱。
5 テーマで**最も明度が高く、最も軽い**。朱の主張が強い。

- 想定: 登壇資料、プロダクト紹介、SNS で 1 枚ずつ流す資料、採用・カルチャー資料
- 性格: 5 テーマで最も明度が高く軽い。朱の主張が強い

> **このテーマが持つのは配色・書体・スケールだけ。** 黒枠やオフセット影のような装飾は持ち込まない。
> **黄を差せるのは D だけ**（§1-3）。E で朱と黄を併用すると温色同士がぶつかり、画面が騒がしくなる。

## 1. カラートークン

```css
:root{
  /* ライト面 */
  --bg:              #FAF4EF;   /* 地（生成り） */
  --surface:         #FFFFFF;   /* カード・パネル面 */
  --ink:             #2B2320;   /* 主テキスト */
  --sub:             #6E5F57;   /* 副テキスト */
  --dim:             #8a7d74;   /* ラベル・ページ番号（本文には使わない。§1-3） */
  --line:            #e5d8ce;   /* 罫線 */

  /* アクセント */
  --accent:          #EE5D43;   /* 面・図形のみ。文字には使わない（§1-3） */
  --accent-deep:     #C24631;   /* 文字用・白文字を載せる塗り用（余裕は小さい。§1-3） */
  --accent-tint:     #FBE3DC;   /* 淡い面 */

  /* ダーク面（面ルールが許可する範囲でのみ使用。§2） */
  --ink-surface:     #2B2320;   /* ダークブロックの地 */
  --on-dark:         #FAF4EF;   /* ダーク面の主テキスト */
  --accent-on-dark:  #FF8A72;   /* ダーク面のアクセント */
  --line-on-dark:    #453a35;   /* ダーク面の罫線 */

  /* 形状・書体 */
  --radius:          4px;
  --ff:    "Zen Kaku Gothic New","Hiragino Sans","Yu Gothic","Meiryo",sans-serif;
  --ff-en: "Manrope","Helvetica Neue",Arial,sans-serif;
}
```

### 1-1. Web フォント

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Zen+Kaku+Gothic+New:wght@500;700;900&family=Manrope:wght@700;800&display=swap" rel="stylesheet">
```

**h1 も h2 も 900**（§3）。C と並んで極太タイポが前提のテーマで、見出しの太さが軽い地色を支えている。

**`--ff` / `--ff-en` のローカル代替は必ず残すこと。** 会場の回線・オフライン環境では CDN が届かない。
特に **Zen Kaku Gothic New が落ちるとヒラギノ／游ゴシックに落ち、900 が出ないため見出しが痩せる**（700 相当で頭打ちになる）。
このテーマは見出しの太さが崩れると地色の軽さだけが残り、資料全体が薄く見える。`capture.js` の警告は必ず確認する。

### 1-2. コントラスト実測値

すべて WCAG 2.1 の相対輝度比で実測済み。

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--ink` / `--bg` | 14.11 | AA 本文可 |
| `--sub` / `--bg` | 5.60 | AA 本文可 |
| `--dim` / `--bg` | 3.66 | **本文不可**・ラベルのみ（§1-3） |
| **`--accent` / `--bg`** | **3.06** | **文字不可**・大文字基準のみ通過（§1-3） |
| **`--accent-deep` / `--bg`** | **4.57** | AA 本文可・**余裕は小さい**（§1-3） |
| **`#fff` / `--accent-deep`（塗りの上）** | **4.98** | AA 本文可・**余裕は小さい**（§1-3） |
| `--ink` / `--accent-tint` | 12.55 | AA 本文可 |
| `--on-dark` / `--ink-surface` | 14.11 | AA 本文可 |
| `--accent-on-dark` / `--ink-surface` | 6.69 | AA 本文可 |

### 1-3. 文字色の規約

1. **`--accent`（`#EE5D43`）を文字色に使わない**（3.06:1）。5 テーマ中でも特に明度が高く、生成り地の上で完全に沈む。強調語・ラベルは **`--accent-deep`（`#C24631`、4.57:1）**
2. **文字を載せる塗りは `--accent-deep` ＋ 白文字**（4.98:1）。`--accent` の塗りは**文字を載せない装飾専用**（区切り帯・ドット・下線・図形）にする
   - 数値と印象が食い違うときは、**文字を明るくするのではなく面を濃くする**
3. **`--accent-deep` の余裕が小さい。**（4.57 / 4.98 で AA の 4.5 をわずかに超えているだけ）
   **小さい文字・細いウェイトで使うと実際には読みにくくなる。強調語は `15px` 以上・`weight 700` 以上で使う。**
   - 本文サイズが `17px` なので、本文中の強調語はこの条件を満たす
   - **KI ラベル（`12px`）・注記・キャプションに `--accent-deep` を使わない**。ここは `--sub` か `--ink`
   - `500` などの細いウェイトで朱を置かない。細らせた瞬間に画面上で霞む
4. **`--dim`（`#8a7d74`）は本文に使わない**。ページ番号・KI ラベル・注記の見出し語専用。読ませる文章は `--sub` 以上
5. ダーク面の上では `--accent-on-dark`（6.69:1）が使える。ライト面より制約が緩く、朱を文字で見せたいときはここ

## 2. 面ルール

| レベル | 規定 |
|---|---|
| **全面ダーク** | **0 枚**。作らない。明るい地であることがこのテーマの value で、表紙も例外にしない |
| **ダークブロック** | 1 スライドに **1 個まで**。デッキ全体で **1〜3 枚**。3 枚連続不可。用途は「ここが結論／主役」を示す 1 要素（テーブルの強調行、対比の主役側、要点バー） |
| **アクセント面** | `--accent` 塗りは 1 スライドに 1 箇所まで。並列カードの一部だけを塗るのは禁止 |

### 2-1. 強調面

専用トークンは持たない。**地を `--surface`（白）、その上のカードを `--bg`（生成り）に反転する**。2〜3 枚に 1 回程度。

---

## 3. スケール（テーマが上書きする 6 値）

| 用途 | 値 |
|---|---|
| h1 サイズ（表紙） | `68px` |
| h1 ウェイト | `900` |
| h2 サイズ（中面見出し） | `34px`（2 行化時のみ `30px`） |
| h2 ウェイト | `900` |
| 本文サイズ | `17px`（最小 `15px`） |
| KI ラベルサイズ | `12px` |

**本文の最小 `15px` は §1-3 の下限と揃えてある。** これ以上縮めると朱の強調語が使えなくなる。
入りきらないときは**文字を縮めず、スライドを分ける**。

**この 6 値以外のサイズ（カード見出し・番号・SVG ラベルの最小値・余白・グリッド）はレイアウト層（`core/rules.md`）が持つ。** テーマ側で上書きしないこと。

## 4. このテーマの空気感

- **朱は 1 スライドに 1 箇所を厳守する。** C のティールより彩度も明度も高く、目が真っ先に行く。2 箇所置いた時点でどちらも効かなくなる
- **箱を減らし、罫線と余白で仕切る。** 生成り地（`#FAF4EF`）と白面（`#FFFFFF`）の差は小さいので、**面を分けたいときは罫線を併用する**
- **広い面は `--accent-tint`、濃い塗りは `--accent-deep` だけ。** `--accent`（`#EE5D43`）を広い面に敷くと画面が朱に持っていかれる。`--accent` は細い帯・ドット・図形の線に留める
- **見出しで語る。** h2 が 34px / 900 あるので、見出しだけで意味が通る文言にする。本文は補助
- 情報量は C と同程度で、**5 テーマの中では少ない側**。遠くから／スマホの小さい表示で読まれる前提なので、余白を大きく取り、1 枚 1 メッセージを厳しく守る
