# テーマ C — モダン

スタートアップ・登壇・SNS 共有前提の資料向け。寒色グレー地にティール、極太タイポ。
5 テーマの中で最も主張が強く、**遠くから読ませる**ことを狙う。

- 想定: 登壇資料、プロダクト紹介、SNS で 1 枚ずつ流す資料、社内の勉強会
- 性格: 寒色地に極太タイポ。5 テーマで最も主張が強い

> **このテーマが持つのは配色・書体・スケールだけ。** 黒枠やオフセット影のような装飾は持ち込まない。
> 1 枚絵なら効く装飾も、複数枚のデッキでは過剰になる。**黄（`--spark`）を持つのは D だけ。**

---

## 1. カラートークン

```css
:root{
  /* ライト面 */
  --bg:              #F0F4F4;   /* 地（寒色グレー） */
  --surface:         #ffffff;   /* カード・パネル面 */
  --ink:             #1C2323;   /* 主テキスト */
  --sub:             #576164;   /* 副テキスト */
  --dim:             #7d8789;   /* ラベル・ページ番号（本文には使わない。§1-3） */
  --line:            #ced6d6;   /* 罫線 */

  /* アクセント */
  --accent:          #0D9488;   /* 面・図形のみ。文字には使わない（§1-3） */
  --accent-deep:     #0F766E;   /* 文字用・白文字を載せる塗り用 */
  --accent-tint:     #d9eae8;   /* 淡い面 */

  /* ダーク面（面ルールが許可する範囲でのみ使用。§2） */
  --ink-surface:     #173B38;   /* ダークブロックの地（ティール寄りの深色） */
  --on-dark:         #F0F4F4;   /* ダーク面の主テキスト */
  --accent-on-dark:  #2fc9b4;   /* ダーク面のアクセント */
  --line-on-dark:    #3a4443;   /* ダーク面の罫線 */

  /* 形状・書体 */
  --radius:          4px;
  --ff:    "Zen Kaku Gothic New","Hiragino Sans","Yu Gothic","Meiryo",sans-serif;
  --ff-en: "Manrope","Helvetica Neue",Arial,sans-serif;
}
```

### 1-1. Web フォント

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Zen+Kaku+Gothic+New:wght@500;700;900&family=Manrope:wght@700;800&display=swap" rel="stylesheet">
```

**Zen Kaku Gothic New の 900 を使えるのがこのテーマの核。** 見出しの太さが他 2 テーマとの差になる。
ローカル代替は必ず残すこと（Zen Kaku が落ちるとヒラギノ／游ゴシックになり、900 が出ないため見出しが痩せる）。

### 1-2. コントラスト実測値

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--ink` / `--bg` | 14.42 | AA 本文可 |
| `--sub` / `--bg` | 5.74 | AA 本文可 |
| `--dim` / `--bg` | 3.33 | **本文不可**・ラベルのみ |
| **`--accent` / `--bg`** | **3.38** | **本文不可**（§1-3） |
| `--accent-deep` / `--bg` | 4.94 | AA 本文可 |
| **`#fff` / `--accent`（塗りの上）** | **3.74** | **本文不可**（§1-3） |
| `#fff` / `--accent-deep`（塗りの上） | 5.47 | AA 本文可 |
| `--ink` / `--accent-tint` | 12.85 | AA 本文可 |
| `--on-dark` / `--ink-surface` | 11.02 | AA 本文可 |
| `--accent-on-dark` / `--ink-surface` | 5.90 | AA 本文可 |

### 1-3. 文字色の規約

1. **`--accent`（`#0D9488`）を文字色に使わない**（3.38:1）。ティールは明度が高く、寒色地の上で沈む。強調語・ラベルは **`--accent-deep`（`#0F766E`、4.94:1）**
2. **文字を載せる塗りは `--accent-deep` ＋ 白文字**（5.47:1）。`--accent` 塗りに白文字は 3.74:1 で不可。`--accent` の塗りは**文字を載せない装飾専用**（区切り帯・ドット・下線）
3. **`--dim` は本文に使わない**。ページ番号・KI ラベル専用
4. ダーク面の上では `--accent-on-dark`（5.90:1）が使える。ここは制約が緩い
5. **`--ink-surface` は純黒にしない。** `#173B38` はティール寄りの深色で、`#1C2323` のような黒に近い値を全面に敷くと安く見える（実制作で指摘された）。ダーク面はテーマの色相を残したまま暗くする

## 2. 面ルール

| レベル | 規定 |
|---|---|
| **全面ダーク** | **0 枚**。作らない。**例外として表紙のみ 1 枚可**（登壇資料で表紙を締める用途） |
| **ダークブロック** | 1 スライドに **1 個まで**。デッキ全体で **1〜3 枚**。3 枚連続不可 |
| **アクセント面** | `--accent` 塗りは 1 スライドに 1 箇所まで。並列カードの一部だけを塗るのは禁止 |

### 2-1. 強調面

**地を `--surface`（白）、その上のカードを `--bg`（寒色グレー）に反転する**。

---

## 3. スケール（テーマが上書きする 6 値）

| 用途 | 値 |
|---|---|
| h1 サイズ（表紙） | `76px` |
| h1 ウェイト | `900` |
| h2 サイズ（中面見出し） | `36px`（2 行化時のみ `32px`） |
| h2 ウェイト | `900` |
| 本文サイズ | `17px`（最小 `15px`） |
| KI ラベルサイズ | `12px` |

**このテーマは字が大きい。** その分 1 枚に入る情報量は 5 テーマで最も少ない。
入りきらないときは**文字を縮めず、スライドを分ける**。

---

## 4. このテーマの空気感

- **タイポで語る。** 見出しが主役で、本文は補助。h2 が 36px / 900 あるので、見出しだけで意味が通る文言にする
- **角丸 4px・箱を減らす。** 面で仕切るより罫線と余白で仕切る
- ティールは「ここが要点」を示す 1 点だけに使う。散らすと寒色地に埋もれる
- 5 テーマの中で最も**余白を大きく取る**。詰めるとこのテーマの良さが消える
- **1 枚 1 メッセージを他テーマより厳しく守る。** 遠くから読まれる前提のため
