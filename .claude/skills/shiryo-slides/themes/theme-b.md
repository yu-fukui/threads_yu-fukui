# テーマ B — 中庸

社内資料・一般的な BtoB 提案向け。クリーム地に温かみのあるオレンジ。
フォーマリティは 5 テーマの中間で、**迷ったらこれ**。

- 想定: 社内共有資料、一般企業への提案、研修・勉強会の配布資料
- 性格: 温かみのあるクリーム地。情報量と読みやすさのバランスが最も取りやすい

---

## 1. カラートークン

```css
:root{
  /* ライト面 */
  --bg:              #faf9f5;   /* 地 */
  --surface:         #ffffff;   /* カード・パネル面 */
  --ink:             #141413;   /* 主テキスト */
  --sub:             #6b6961;   /* 副テキスト */
  --dim:             #87857c;   /* ラベル・ページ番号（本文には使わない。§1-3） */
  --line:            #dcd6c5;   /* 罫線 */

  /* アクセント */
  --accent:          #d97757;   /* 面・図形。文字には使わない（§1-3） */
  --accent-deep:     #a85336;   /* 文字用・白文字を載せる塗り用 */
  --accent-tint:     #f7eae3;   /* 淡い面 */

  /* ダーク面（面ルールが許可する範囲でのみ使用。§2） */
  --ink-surface:     #141413;   /* ダーク面の地 */
  --on-dark:         #faf9f5;   /* ダーク面の主テキスト */
  --accent-on-dark:  #e8946f;   /* ダーク面のアクセント */
  --line-on-dark:    #3a3937;   /* ダーク面の罫線 */

  /* 形状・書体 */
  --radius:          8px;
  --ff:    "Noto Sans JP", "Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif;
  --ff-en: "Inter", "Helvetica Neue", Arial, sans-serif;
}
```

### 1-1. Web フォント

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700;900&family=Inter:wght@400;600;700;800&display=swap" rel="stylesheet">
```

**`--ff` / `--ff-en` のローカル代替は必ず残すこと。** 社内プロキシで Google Fonts が塞がれた環境・オフライン環境では CDN が届かず、代替が無いと環境依存の既定フォントに落ちる。`capture.js` は撮影時にフォントが届いたかを検査し、落ちていれば警告する。

### 1-2. コントラスト実測値

すべて WCAG 2.1 の相対輝度比で実測済み。

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--ink` / `--bg` | 17.50 | AA 本文可 |
| `--sub` / `--bg` | 5.22 | AA 本文可 |
| `--dim` / `--bg` | 3.51 | **本文不可**・大きめラベルのみ |
| `--accent-deep` / `--bg` | 5.04 | AA 本文可 |
| `--accent-deep` / `--accent-tint` | 4.51 | AA 本文可 |
| `--ink` / `--accent-tint` | 15.65 | AA 本文可 |
| `--ink` / `--accent`（塗りの上） | 5.90 | AA 本文可 |
| **`#fff` / `--accent`（塗りの上）** | **3.12** | **不可**（§1-3） |
| `#fff` / `--accent-deep`（塗りの上） | 5.31 | AA 本文可 |
| `--on-dark` / `--ink-surface` | 17.50 | AA 本文可 |
| `--accent-on-dark` / `--ink-surface` | 7.81 | AA 本文可 |

### 1-3. 文字色の規約

1. **`--accent`（`#d97757`）を文字色に使わない。** 地に対して 2.96:1 しかなく、WCAG の大文字基準 3:1 にすら届かない。見出しの強調語やラベルに使いたい場合は **`--accent-deep`（`#a85336`、5.04:1）** を使う
2. **文字を載せる塗りは `--accent-deep` ＋ 白文字にする**（5.31:1）。
   `--accent`（`#d97757`）の塗りは**文字を載せない装飾専用**（フェーズバー・区切り帯・ドット）にする。
   - `--accent` 塗りに白文字は **3.12:1** で不可。数値上は `--ink`（5.90:1）が通るが、**濃い面に黒文字は視覚的に重く、「コントラストが悪い」と受け取られる**（実プロジェクトで指摘された）
   - 数値と印象が食い違うときは、**文字を明るくするのではなく面を濃くする**。これで両方が満たせる
3. **`--dim` は本文に使わない。** ページ番号・KI ラベル・「出典」などの短い補助ラベル専用。読ませる文章は `--sub` 以上

## 2. 面ルール

| レベル | 規定 |
|---|---|
| **全面ダーク** | デッキ全体で **2 枚まで**。用途は表紙・最終サマリーに限る。連続不可 |
| **ダークブロック** | 1 スライドに **1 個まで**。デッキ全体で **3 枚まで**。3 枚連続不可。用途は「ここが結論／主役」を示す 1 要素（対比の主役側、テーブルの強調行、POINT バー） |
| **アクセント面** | `--accent` 塗りは 1 スライドに 1 箇所まで。並列カードの一部だけを塗るのは禁止 |

### 2-1. 強調面（淡い面のスライド）

専用トークンは持たない。**地を `--surface`（白）、その上のカードを `--bg`（クリーム）に反転する**ことで表現する。2〜3 枚に 1 回程度。

## 3. スケール（テーマが上書きする 6 値）

| 用途 | 値 |
|---|---|
| h1 サイズ（表紙） | `64px` |
| h1 ウェイト | `800` |
| h2 サイズ（中面見出し） | `30px`（2 行化時のみ `28px`） |
| h2 ウェイト | `700` |
| 本文サイズ | `16px`（最小 `14px`） |
| KI ラベルサイズ | `12px` |

**この 6 値以外のサイズ（カード見出し・番号・SVG ラベルの最小値・余白・グリッド）はレイアウト層（`core/rules.md`）が持つ。** テーマ側で上書きしないこと。

## 4. このテーマの空気感

- **箱を使いすぎない。** 罫線と余白で仕切るのが基本。カードは「まとまりを明示する必要がある」ときだけ
- **角丸 8px** はカード・チップ・バッジに一律。ボタン風の要素は作らない（スライドに押せるものは無い）
- クリーム地（`#faf9f5`）と白面（`#ffffff`）の差は小さい。**面を分けたいときは罫線を併用する**
- オレンジは「1 スライドに 1 箇所」。全体を通して**差し色として効かせる**もので、装飾として散らさない
