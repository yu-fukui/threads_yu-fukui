# テーマ A — 堅い

金融・行政・大企業への提案、硬めの業務資料向け。白地にコーポレートブルー。
5 テーマの中で最もフォーマルで、装飾を持たない。

- 想定: 金融・行政・インフラ・大企業への提出資料、社内の正式な報告
- 性格: 装飾を持たず、罫線と余白だけで組む。5 テーマで最もフォーマル

---

## 1. カラートークン

```css
:root{
  /* ライト面 */
  --bg:              #ffffff;   /* 地 */
  --surface:         #f6f8fd;   /* カード・パネル面（ごく淡いブルー） */
  --ink:             #0f172a;   /* 主テキスト */
  --sub:             #64748b;   /* 副テキスト */
  --dim:             #7c8ba1;   /* ラベル・ページ番号（本文には使わない。§1-3） */
  --line:            #e2e8f0;   /* 罫線 */

  /* アクセント */
  --accent:          #3d5dc6;   /* 面・図形。このテーマでは文字にも使える（§1-3） */
  --accent-deep:     #2e47a6;   /* 濃アクセント・白文字を載せる塗り用 */
  --accent-tint:     #eef2fb;   /* 淡い面 */

  /* ダーク面（面ルールが許可する範囲でのみ使用。§2） */
  --ink-surface:     #324c9e;   /* 紺ブロックの地 */
  --on-dark:         #ffffff;   /* 紺面の主テキスト */
  --accent-on-dark:  #aec2f2;   /* 紺面のアクセント（大きめの文字専用） */
  --line-on-dark:    #5570b8;   /* 紺面の罫線（装飾のみ） */

  /* 形状・書体 */
  --radius:          4px;
  --ff:    "Noto Sans JP","Hiragino Sans","Yu Gothic","Meiryo",sans-serif;
  --ff-en: "Source Code Pro","SFMono-Regular",Menlo,monospace;
}
```

### 1-1. Web フォント

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500;700&family=Source+Code+Pro:wght@500;600;700&display=swap" rel="stylesheet">
```

欧文に等幅（Source Code Pro）を当てるのがこのテーマの特徴。KI ラベル・番号・日付が硬く締まる。
**本文の和文には使わない**（読みにくくなる）。

`--ff` / `--ff-en` のローカル代替は必ず残すこと。

### 1-2. コントラスト実測値

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--ink` / `--bg` | 17.85 | AA 本文可 |
| `--sub` / `--bg` | 4.76 | AA 本文可 |
| `--dim` / `--bg` | 3.46 | **本文不可**・ラベルのみ |
| `--accent` / `--bg` | 5.87 | AA 本文可 |
| `--accent-deep` / `--bg` | 8.18 | AA 本文可 |
| `#fff` / `--accent`（塗りの上） | 5.87 | AA 本文可 |
| `#fff` / `--accent-deep`（塗りの上） | 8.18 | AA 本文可 |
| `--ink` / `--accent-tint` | 15.92 | AA 本文可 |
| `--on-dark` / `--ink-surface` | 7.89 | AA 本文可 |
| `--accent-on-dark` / `--ink-surface` | 4.43 | 大文字のみ |

### 1-3. 文字色の規約

1. **このテーマは `--accent` を文字色に使える**（5.87:1）。5 テーマの中でここだけの特例
2. **ただし文字を載せる塗りは `--accent-deep` ＋ 白文字にする**。全テーマ共通の規則で、A でも 8.18:1 と数値が上がるため従う
3. **`--dim` は本文に使わない**。ページ番号・KI ラベル・注記の見出し語専用
4. `--accent-on-dark` は 4.43:1。**紺面の上で本文には使わない**。ラベル・大きめの数字だけ
5. **Royal Blue 系（`#2547e3` 等）を持ち込まない**。このテーマは `--accent` の濃淡だけで組む

## 2. 面ルール

| レベル | 規定 |
|---|---|
| **全面ダーク** | **0 枚**。作らない。このテーマはライト基調が思想 |
| **紺ブロック** | 1 スライドに **1 個まで**。デッキ全体で **1〜3 枚**。3 枚連続不可。用途は「ここが結論／主役」を示す 1 要素（テーブルの強調行、対比の主役側、要点バー） |
| **アクセント面** | `--accent` 塗りは 1 スライドに 1 箇所まで |

### 2-1. 強調面

専用トークンは持たない。**地を `--surface`（淡ブルー）、その上のカードを `--bg`（白）に反転する**。2〜3 枚に 1 回程度。

## 3. スケール（テーマが上書きする 6 値）

| 用途 | 値 |
|---|---|
| h1 サイズ（表紙） | `56px` |
| h1 ウェイト | `700` |
| h2 サイズ（中面見出し） | `28px`（2 行化時のみ `26px`） |
| h2 ウェイト | `700` |
| 本文サイズ | `15px`（最小 `13.5px`） |
| KI ラベルサイズ | `11px` |

**ウェイトの上限は 700。** 800 / 900 を使わない。太らせると硬さが崩れる。

---

## 4. このテーマの空気感

- **装飾をしない。** 罫線と余白だけで組む。アイコンも「無いと伝わらない」ときだけ
- **角丸 4px。** ほぼ直角に見える硬さを保つ
- 白地（`--bg`）と淡ブルー面（`--surface`）の差は小さい。**面を分けるときは罫線を併用する**
- 青は情報の階層を示すために使う。感情を出す色ではない
- 5 テーマの中で最も**情報量を詰めてよい**。手元で読む前提の資料が主用途
